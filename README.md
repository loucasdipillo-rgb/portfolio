# Loucas Di Pillo — Personal Portfolio

Personal portfolio website for Loucas Di Pillo, Master's student in Macroeconomics & Finance at HEC Liège.

Built as a single self-contained HTML file — no framework, no build step, no dependencies.

**Live site:** [loucasdipillo-rgb.github.io/portfolio](https://loucasdipillo-rgb.github.io/portfolio)

## Structure

```
portfolio/
├── index.html              # Entire website (HTML + CSS + JS, self-contained)
├── CV-Loucas_DiPillo.pdf   # CV linked from the hero section
├── images/                 # Profile photo and gallery images
└── projects/               # PDF reports linked from project cards
```

## Sections

Hero · About · Education · Experience · Certifications · Skills · Projects · Gallery · Contact

## Tech

Pure HTML/CSS/JS — no framework, no build step. Fonts via Google Fonts (Space Grotesk + Inter). Deploy to any static host (GitHub Pages, Netlify, Vercel).

## Deploy

The site is deployed via GitHub Pages from the `main` branch root.
